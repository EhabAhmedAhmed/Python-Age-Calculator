# Python Age Calculator

## About the Project
A beginner-friendly Python project that calculates people's ages from their birth dates and identifies the oldest and youngest person.

## Features
- Calculate age from date of birth.
- Display the day of the week a person was born.
- Handle invalid date inputs.
- Store people's information in a list.
- Find the oldest and youngest person.

## Concepts Used
- Python Functions and Loops
- Lists and Dictionaries
- `datetime`
- Exception Handling
- `max()`, `min()`, and `lambda`

## How to Run
Run the following command:

```bash
python age_calculator.py
```
